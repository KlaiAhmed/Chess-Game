## Chess Game

 a **Chess Game** built from scratch using **Python** and **Pygame**! 🎮

### Features
- Full chess rules implementation (castling, en passant, stalemate detection)  
- Single-player mode with AI opponent (minimax algorithm)  

### Known Issues
- Pawn promotion sometimes assigns the wrong color. Working on a fix!
